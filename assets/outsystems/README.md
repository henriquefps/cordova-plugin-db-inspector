# OutSystems action icons

Icons for the public client actions of the `CordovaDBInspector` O11 library, in the plugin's blue (`#2063b0`) with [Phosphor Icons](https://phosphoricons.com) glyphs (MIT).

| Action | Glyph |
|---|---|
| `CheckDbInspectorPlugin` | `plug` (fill) |
| `OpenInspector` | `magnifying-glass` (bold) |
| `ListDatabases` | `stack` (bold) |
| `RunQueries` | `play` (fill) |

Each comes as an SVG source and PNGs at 16, 32 and 64 px. The library uses the 32 px PNGs (in Service Studio: select the action, then the **Icon** property).
